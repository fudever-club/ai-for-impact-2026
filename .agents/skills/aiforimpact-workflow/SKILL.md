# AI for Impact 2026 – Workspace Workflow & Engineering Skill

Specialized development, design, and verification workflow for the official **AI for Impact 2026** competition portal (`AI.Impact.fptu.vn`), developed by **CLB Lập Trình FU-DEVER** for **Trường Đại học FPT Đà Nẵng**.

## Core Invariants & Architecture

1. **Single Source of Truth (SSOT)**:
   - All factual data (event dates, registration links, stage descriptions, programming challenge rules, topic list, prizes, organizers) originates in [`content/site-config.ts`](file:///c:/Users/ADMIN/_Project/AIforImpact/content/site-config.ts).
   - Component templates consume computed view-models generated by [`content/view-model.ts`](file:///c:/Users/ADMIN/_Project/AIforImpact/content/view-model.ts).
   - **Never hardcode** operational figures (e.g. `Top 24`, `240 phút`, prize amounts) directly into locale strings or JSX components. Use dynamic interpolation tokens (`{qualifiedTeams}`, `{duration}`).

2. **Brand & Identity Invariants**:
   - **No Unofficial Competition Logo**: The contest does not possess a graphic emblem. Use strictly the typographic Brand Lockup (`AI FOR IMPACT 2026`).
   - **Official FPT 3-Color Vector Symbol & Favicon Suite**: The header brand lockup features [`components/icons/FptSymbol.tsx`](file:///c:/Users/ADMIN/_Project/AIforImpact/components/icons/FptSymbol.tsx). The browser favicon and app icons are strictly generated via `scripts/build-favicons.mjs` producing multi-resolution FPT 3-color icons (`app/favicon.ico`, `app/icon.svg`, `public/icon.svg`, `public/apple-touch-icon.png`).
   - **Developer Credit & FU-DEVER Brand**: Website footer must include the official *"Developed by FU-DEVER"* badge linking directly to [`https://fudever.com`](https://fudever.com).
   - **Organizers Display (`#organization`)**: Clean, dignified centered institution card (`max-w-2xl mx-auto`) featuring official FPT University Da Nang logo (`/brand/fpt-university.png`) without cliché filler cards.

3. **Design System (Clean Tech Light)**:
   - **Backgrounds**: Crisp white (`#FFFFFF`) and layered porcelain slate (`#F8FAFC`, `#F1F5F9`).
   - **Text**: Deep slate (`#0F172A` headings, `#334155` body, `#64748B` muted).
   - **Accents**: FPT Orange (`#FF6B00`, hover `#EA580C`) and Tech Blue (`#2563EB`).
   - **Surfaces**: `.glass-card` (white frosted cards with `shadow-card`, `shadow-card-hover`), `.glass-card-orange` (warm amber/orange gradient for Champion podium & Register CTA).
   - **Clean Tech Light IDE Window**: Cửa sổ môi trường lập trình ICPC với mặt kính trắng mờ (`bg-white/95 backdrop-blur-md`), Mac Titlebar thanh lịch, nút copy lệnh biên dịch và bộ SVG vector chính hãng từ [Svgl](https://svgl.app/) (C, C++, Java, Python).
   - **Language**: Single unified Vietnamese interface (language switcher disabled).

4. **Tech Vector Suite ([Svgl](https://svgl.app/))**:
   - All technologies, compilers, and AI frameworks are served via crisp SVGs in `public/icons/`:
     - Compilers: `c.svg`, `cpp.svg`, `java.svg`, `python.svg`
     - AI Models: `openai.svg`, `claude.svg`, `gemini.svg`, `deepseek.svg`, `huggingface.svg`
     - Deployment & Support: `docker.svg`, `zalo.svg`

5. **Operational Locked Facts**:
   - **Registration Deadline**: Closes at **23:59:59 on September 25, 2026**.
   - **Candidate Support Channel**: Official Zalo support group `https://zalo.me/g/ukzv6t0i6ctyj16lfrum` with authentic Zalo vector icon.
   - **Training Workshops (Stage 3)**: Session 1 (07/10), Session 2 (08/10), Session 3 (09/10) without detailed time schedules on the public page.
   - **Information Density**: Overall participant count and Stage 1 deliverables are withheld from public display per BTC directives.

## Verification Pipeline & Deployment

Before committing any code or declaring a task complete, run the complete 4-step quality gate:

```bash
# 1. Kiểm tra kiểu TypeScript (0 lỗi)
npm run typecheck

# 2. Kiểm tra chuẩn mã nguồn ESLint (0 cảnh báo / lỗi)
npm run lint

# 3. Chạy 100% bộ kiểm thử tự động Vitest (52/52 tests pass)
npm test

# 4. Biên dịch xuất bản tĩnh Next.js Static Export
npm run build
```

### Triển khai Sản xuất (Production Release):
```bash
# Push mã nguồn lên GitHub Organization
git push origin main

# Deploy trực tiếp lên Vercel Production
npx vercel --prod --yes
```
