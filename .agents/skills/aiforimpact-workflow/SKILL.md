# AI for Impact 2026 – Workspace Workflow & Engineering Skill

Specialized development, design, and verification workflow for the official **AI for Impact 2026** competition portal (`AI.Impact.fptu.vn`), developed by **CLB Lập Trình FU-DEVER** for **Trường Đại học FPT Đà Nẵng**.

## 1. Core Invariants & Architecture

1. **Single Source of Truth (SSOT)**:
   - All factual operational data (event dates, registration links, stage descriptions, programming challenge rules, topic list, prizes, organizers) originates in [`content/site-config.ts`](file:///c:/Users/ADMIN/_Project/AIforImpact/content/site-config.ts).
   - Component templates consume computed view-models generated by [`content/view-model.ts`](file:///c:/Users/ADMIN/_Project/AIforImpact/content/view-model.ts).
   - **Never hardcode** operational figures (e.g. `Top 24`, `240 phút`, prize amounts) directly into locale strings or JSX components. Use dynamic interpolation tokens (`{qualifiedTeams}`, `{duration}`).

2. **Cấu trúc Lộ trình 4 Chặng Chuẩn hóa (The 4-Stage Journey)**:
   - **Chặng 1: Đăng ký & Đề xuất Ý tưởng (14/09 – 25/09/2026)**: Đăng ký thành viên trực tuyến, nộp hồ sơ mô tả đề xuất ý tưởng/kiến trúc giải pháp. **Tuyệt đối không yêu cầu video 3 phút** (đã hủy bỏ theo chỉ đạo BTC).
   - **Chặng 2: Vòng loại – Tư duy Lập trình ICPC (02/10/2026)**: Thử thách giải thuật 240 phút tại trường theo chuẩn ICPC Global 2024. Chọn ra Top 24 đội.
   - **Chặng 3: Chương trình Huấn luyện Thực chiến (07/10 – 09/10/2026)**: 3 workshop chuyên sâu (Kiến trúc & Sửa lỗi Agent, Đánh giá & Bảo mật, Thi đấu thử nghiệm Mock Run) kèm buổi mentoring 1-1.
   - **Chặng 4: Vòng Chung kết & Trình diễn Sản phẩm (31/10/2026)**: Khóa mã nguồn Baseline 23h59 ngày 28/10; sáng 31/10 thi Build Sprint 02 giờ tại chỗ tích hợp ràng buộc bổ sung bất ngờ (chấm 20 điểm trên Git Diff); Demo Day & Pitching (08 phút demo + 04 phút phản biện).
   - *Lưu ý:* Vòng Kỹ thuật ngày 17/10 cũ đã bị bãi bỏ hoàn toàn, gộp vào Chung kết.

3. **Cơ chế Đánh giá & Hệ sinh thái Hỗ trợ Thí sinh (`#evaluation`)**:
   - **3 Nguyên tắc Đánh giá Cốt lõi**: Chấm tự động bằng Test Case chuẩn ICPC, Kiểm tra Trace Log & Năng lực Làm chủ, Sản phẩm phải chạy thực tế (No Fake Demo).
   - **Tinh giản Barem Điểm trên Landing Page**: Theo chỉ đạo trực tiếp của BTC (*"Cũng bỏ luôn em, sẽ có nhóm support riêng nên ko cần thiết đưa hết lên web"*), **tuyệt đối không đưa barem chi tiết 11 tiêu chí, thẻ phần trăm trọng số 30%/70% hay banner công thức tính điểm lên web công khai**.
   - **Kênh Hỗ trợ Zalo**: Bắt buộc dùng **Logo Zalo vector chính hãng** (`/icons/zalo.svg`) trên nút hỗ trợ Zalo.
   - **Nút Tải Sổ tay Thí sinh**: Hiển thị sạch sẽ **"Tải Sổ tay Thí sinh"**, xuất file `So_tay_thi_sinh_AI-for-Impact-2026.docx`, **tuyệt đối không để lộ hậu tố phiên bản nội bộ `(V4)`**.
   - **2 Điểm chạm Tải Sổ tay**: Duy trì cả 2 vị trí (cuối Lộ trình `#journey` và trong thẻ Hỗ trợ tại `#evaluation`) phục vụ 2 ngữ cảnh tâm lý khác nhau của thí sinh.

4. **Chuẩn mực Văn phong Kỹ thuật (Vietnamese Tech Writer)**:
   - Giữ nguyên các thuật ngữ tiếng Anh chuẩn mực quốc tế: `Trace log`, `System Prompt`, `Temperature`, `Harness Engineering`, `Prompt Injection`, `Circuit Breaker`, `Git Diff`, `Baseline`, `Build Sprint`, `Demo Day`.
   - Tuyệt đối không dịch gượng gạo sang tiếng Việt gây khó hiểu cho thí sinh và ban giám khảo.

5. **Hệ thống Typography & Chuyển động Mượt mà (Motion Design)**:
   - **02 Fonts Chuẩn mực**: `Inter` (Display & Sans) cho toàn bộ tiêu đề và nội dung; `JetBrains Mono` (Mono) cho khối code, compiler specs ICPC và countdown. Đã loại bỏ `Space Grotesk` để triệt tiêu lỗi lệch dấu tiếng Việt.
   - **Animation Không Giật Lag**: Triển khai CSS Grid row transitions (`grid-template-rows: 0fr -> 1fr`) kết hợp đường cong gia tốc tự nhiên `--ease-out-expo` (`cubic-bezier(0.16, 1, 0.3, 1)`), triệt tiêu hoàn toàn layout reflow.

6. **Brand & Identity Invariants**:
   - **Cuộc thi KHÔNG CÓ LOGO CHÍNH THỨC**: Dùng Brand Lockup dạng chữ (`AI FOR IMPACT 2026`) kết hợp Biểu tượng FPT 3 màu vector chuẩn (`FptSymbol.tsx`) tại Header.
   - **Bộ Favicon Đa Độ Phân Giải**: FPT 3 màu trên squircle trắng do `scripts/build-favicons.mjs` biên dịch (`app/favicon.ico`, `app/icon.svg`, `public/icon.svg`, `public/apple-touch-icon.png`).
   - **Huy hiệu Đơn vị Phát triển**: Footer hiển thị *"Developed by FU-DEVER"* trỏ trực tiếp về [`https://fudever.com`](https://fudever.com).
   - **Đơn vị Tổ chức (`#organization`)**: Thẻ trung tâm đối xứng (`max-w-2xl mx-auto`), trang trọng, không dùng thẻ phụ cliché.

## 2. Verification Pipeline & Production Deployment

Trước khi cam kết mã nguồn hoặc đóng task, bắt buộc hoàn thành toàn bộ quy trình kiểm định 4 bước:

```bash
# 1. Kiểm tra kiểu TypeScript Strict (0 lỗi)
npm run typecheck

# 2. Kiểm tra chuẩn mã nguồn ESLint (0 cảnh báo / lỗi)
npm run lint

# 3. Chạy 100% bộ kiểm thử tự động Vitest (52/52 tests pass)
npm test

# 4. Biên dịch xuất bản tĩnh Next.js Static Export
npm run build
```

### Quy trình Xuất bản (Release to Production):
```bash
# Push commit lên GitHub Organization (Kích hoạt CI Quality Gate & Vercel Auto-Deploy)
git push origin main

# Kiểm tra phản hồi trực tiếp trên trang Production
node -e "fetch('https://ai.impact.fptu.vn/vi').then(r => console.log('HTTP Status:', r.status))"
```
