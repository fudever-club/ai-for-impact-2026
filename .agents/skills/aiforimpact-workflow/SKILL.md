# AI for Impact 2026 – Workspace Workflow & Engineering Skill

Specialized development, design, and verification workflow for the official **AI for Impact 2026** competition portal (`AI.Impact.fptu.vn`).

## Core Invariants & Architecture

1. **Single Source of Truth (SSOT)**:
   - All factual data (event dates, registration links, stage descriptions, programming challenge rules, topic list, prizes, organizers) originates in [`content/site-config.ts`](file:///c:/Users/ADMIN/_Project/AIforImpact/content/site-config.ts).
   - Component templates consume computed view-models generated by [`content/view-model.ts`](file:///c:/Users/ADMIN/_Project/AIforImpact/content/view-model.ts).
   - **Never hardcode** operational figures (e.g. `Top 24`, `240 phút`, prize amounts) directly into locale strings or JSX components. Use dynamic interpolation tokens (`{qualifiedTeams}`, `{duration}`).

2. **Design System (Clean Tech Light)**:
   - **Backgrounds**: Crisp white (`#FFFFFF`) and layered porcelain slate (`#F8FAFC`, `#F1F5F9`).
   - **Text**: Deep slate (`#0F172A` headings, `#334155` body, `#64748B` muted).
   - **Accents**: FPT Orange (`#FF6B00`, hover `#EA580C`) and Tech Blue (`#2563EB`).
   - **Surfaces**: `.glass-card` (elevated white frosted cards with soft multi-layer diffuse shadows `shadow-card`, `shadow-card-hover`), `.glass-card-orange` (warm amber/orange gradient for Champion podium & Register CTA).
   - **Terminal**: Sleek slate-900 developer console for ICPC compilers with live syntax badges.
   - **Language**: Single unified Vietnamese interface (language switcher disabled).

3. **Verification Pipeline**:
   Before committing any code or declaring a task complete, run:
   ```bash
   npm run typecheck   # TypeScript check (0 errors)
   npm run lint        # ESLint check (0 warnings/errors)
   npm test            # Vitest unit & parity test suite (all 42+ tests pass)
   npm run build       # Next.js static export (generates out/)
   ```

4. **Live Server Sync**:
   When serving static export via `npx serve out -l 3000`:
   ```bash
   robocopy .worktrees\implementation\out out /E /PURGE
   ```

5. **TencentDB Agent Memory Hub Integration**:
   Capture key decisions and milestone turns into the centralized memory hub:
   ```bash
   node c:/Users/ADMIN/_Project/agent-memory-hub/connectors/memory_cli.mjs capture "<Request>" "<Solution/Decision>" aiforimpact
   ```
